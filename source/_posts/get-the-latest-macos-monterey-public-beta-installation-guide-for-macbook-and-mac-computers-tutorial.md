### 1\. Register your device with the Developer Beta Access Utility

1. Download the MacOS Developer Beta Access utility from [Apple's Developer page](https://developer.apple.com/xcode/resources/).
2. Run the Developer Beta Access app and sign up to get access.
3. This enables Developer Betas to be downloadable from the Software Update app in your device's System Settings.

A restart may be required.

### 2\. Download the beta version of MacOS 15 Sequoia

1. Open System Settings > General > Software Update, then click the info button next to "Beta updates."
2. Select the MacOS Developer beta.
3. Click "Done."
4. Approve the download of the installation.

Once beta access is made open to the public in July, the process will be identical, without the caveat of first registering with the developer utility.

Also, ensure that you have MacOS 10.8 or later, as the beta access utility won't work on earlier versions of the operating system.
